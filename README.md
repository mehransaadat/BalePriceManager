# ربات ارسال قیمت در بله

## قبل از هر چیز: محدودیت مهم پلتفرم بله

ربات‌های بله (دقیقاً مثل تلگرام) **نمی‌توانند مستقیماً با شماره تلفن** به کسی پیام بدهند.
ربات فقط می‌تواند به کسانی پیام بفرستد که قبلاً خودشان یک‌بار ربات را در بله باز کرده و
`/start` زده‌اند (یعنی `chat_id` آن‌ها ثبت شده باشد).

برای همین، این نسخه این‌طور کار می‌کند:
1. هر کاربر باید یک‌بار ربات را استارت کند و شماره تماسش را (با دکمه‌ای که ربات نشان می‌دهد) بفرستد.
2. شما (ادمین) وقتی فایل قیمت را برای ربات می‌فرستید:
   - اگر **بدون توضیح (caption)** بفرستید → به همهٔ کاربران ثبت‌شده ارسال می‌شود.
   - اگر در قسمت **توضیح فایل** لیست شماره‌ها را (با کاما یا خط جدید جدا) بنویسید → فقط به همان
     شماره‌ها ارسال می‌شود (به شرطی که قبلاً ربات را استارت کرده باشند). شماره‌هایی که هنوز ربات
     را استارت نکرده باشند، در گزارش پایانی به شما اعلام می‌شوند.

اگر واقعاً نیاز دارید بدون هیچ تعامل قبلی، مستقیم به هر شماره‌ای پیام بفرستید، بله سرویس
سازمانی جداگانه‌ای به اسم «سفیر» (`safir.bale.ai`) دارد که این کار را ممکن می‌کند؛ این کد از
حالا آماده‌ی اتصال به آن است (بخش «سرویس سفیر» در پایین همین فایل را ببینید)، اما نیاز به
ثبت‌نام کسب‌وکار در پنل بله (`bale.ai/org`)، گرفتن اشتراک و در برخی حالت‌ها تأیید قالب پیام از
پشتیبانی بله دارد.

## مراحل راه‌اندازی

### ۱. ساخت ربات و گرفتن توکن
1. در بله با ربات `@BotFather` (یا معادل آن که در مستندات bale.ai/dev معرفی شده) چت کنید.
2. یک ربات جدید بسازید و توکن را کپی کنید.

### ۲. نصب پیش‌نیازها
```bash
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
```bash
export BALE_BOT_TOKEN="توکن ربات شما"
export BALE_ADMIN_CHAT_ID="0"   # فعلاً صفر بگذارید
```

### ۴. اجرای اول برای پیدا کردن chat_id خودتان
```bash
python bot.py
```
سپس از اکانت بله خودتان به ربات پیام بدهید (مثلاً `/start`). در کنسول خط
`پیام دریافت شد از chat_id=...` چاپ می‌شود؛ همان عدد را کپی کنید.

سپس برنامه را متوقف کنید (Ctrl+C)، مقدار `BALE_ADMIN_CHAT_ID` را با همان عدد
جایگزین کنید و دوباره اجرا کنید:
```bash
export BALE_ADMIN_CHAT_ID="123456789"
python bot.py
```

### ۵. تست کامل
1. با یک یا چند اکانت دیگر ربات را استارت کرده و شماره تماس را ارسال کنید.
2. از اکانت ادمین، یک فایل متنی (با هر پسوندی یا بدون پسوند) که هر خطش به شکل
   `نام محصول    قیمت` است برای ربات بفرستید.
3. ربات جدول را می‌سازد و برای کاربران ثبت‌شده ارسال می‌کند، و یک گزارش
   (تعداد موفق/ناموفق) به شما برمی‌گرداند.

## فرمت فایل قیمت
هر خط یک محصول است. جداکنندهٔ نام و قیمت می‌تواند یکی از این‌ها باشد: تب،
دو یا چند فاصله، ویرگول، یا سمی‌کالن. مثال:
```
پنیر لیقوان        185000
روغن آفتابگردان     420000
برنج طارم درجه یک   980000
```
ربات این‌ها را در قالب یک جدول با فونت ثابت (monospace) داخل بلاک کد ارسال می‌کند
تا ستون نام و قیمت هرگز جابه‌جا نشوند.

## دستورات و منوی ادمین
- `/panel` — منوی دکمه‌ای ادمین را باز می‌کند:
  - **📋 آپلود لیست شماره مشتریان** — بعد از زدن این دکمه، هر فایل اکسل/متنی بعدی که
    بفرستید به‌عنوان «لیست کامل مشتریان» ذخیره می‌شود (جایگزین لیست قبلی). یک شماره در
    هر سطر یا سلول کافی است؛ فرمت شماره مهم نیست (۰۹۱۲...، +۹۸۹۱۲...، یا فاصله‌دار)،
    خودش تمیز و یکدست می‌شود.
  - **💰 آپلود فایل قیمت و موجودی** — بعد از این دکمه، فایل بعدی همان فایل قیمتی‌ست که قبلاً
    مستقیم می‌فرستادید؛ تفاوتش این است که این‌بار به‌صورت پیش‌فرض فقط به شماره‌های همان
    «لیست مشتریان» بالا ارسال می‌شود (نه لزوماً همهٔ کاربران ثبت‌شده در ربات).
  - **📊 گزارش آخرین ارسال** — می‌گوید آخرین بار فایل قیمت به چند شماره رسید، به چند شماره
    نرسید (چون آن شماره‌ها ربات را استارت نکرده‌اند)، و لیست همان شماره‌های نرسیده را
    می‌دهد (اگر لیست طولانی باشد، به‌صورت فایل اکسل هم ضمیمه می‌شود).
  - **🔁 تلاش دوباره برای جامانده‌ها (سفیر)** — همان شماره‌های نرسیدهٔ آخرین ارسال را از طریق
    سرویس سفیر (پیام مستقیم بله، بدون نیاز به استارت‌کردن) دوباره مطلع می‌کند. تا وقتی
    `SAFIR_API_ACCESS_KEY` و `SAFIR_BOT_ID` تنظیم نشده باشند، این دکمه فقط یک پیام راهنما
    می‌دهد و کاری نمی‌کند — یعنی خیالتان راحت باشد، بدون این دو مقدار هم بقیهٔ ربات
    کامل کار می‌کند.
- برای گزارش یک تاریخ خاص (نه فقط آخرین ارسال) بنویسید: `گزارش 1405-06-11`
- `/count` — تعداد کاربران استارت‌کرده و تعداد شماره‌های لیست اصلی مشتریان را نشان می‌دهد.
- `/queue` — تعداد آیتم‌های در صفِ در حال ارسال را نشان می‌دهد.
- روش قدیمی هم هنوز کار می‌کند: فایل قیمت را بدون زدن هیچ دکمه‌ای مستقیم بفرستید (با یا
  بدون caption لیست شماره‌ها) تا رفتار قبلی (broadcast به همهٔ کاربران ثبت‌شده) انجام شود.

## سرویس سفیر (ارسال مستقیم به شماره، بدون نیاز به استارت قبلی)
وقتی از پنل کسب‌وکار بله (`bale.ai/org`) کلید دسترسی و شناسهٔ بازو را گرفتید، همین دو خط را
قبل از اجرا تنظیم کنید (یا مستقیم در بالای `bot.py` در `SAFIR_API_ACCESS_KEY` /
`SAFIR_BOT_ID` قرار دهید):
```bash
export SAFIR_API_ACCESS_KEY="کلید-دسترسی-شما"
export SAFIR_BOT_ID="شناسه-بازوی-شما"
```
از همان لحظه، دکمهٔ «🔁 تلاش دوباره برای جامانده‌ها» فعال می‌شود. توجه کنید سرویس سفیر فقط
**متن** می‌فرستد (نه فایل اکسل)؛ به همین دلیل برای شماره‌های جامانده یک پیامِ «لطفاً ربات را
استارت کنید» می‌فرستد تا خودشان فایل کامل را از طریق ربات دریافت کنند. اگر مستندات رسمی سفیر
(`docs.bale.ai/safir`) پشتیبانی از ارسال سند/فایل را هم تأیید کرد، می‌شود آن را هم اضافه کرد.

## نکات برای مرحلهٔ بعد (production)
- این نسخه با polling (`getUpdates`) کار می‌کند که برای تست عالی است؛ برای اجرای
  دائم روی سرور بهتر است به webhook مهاجرت کنید.
- دیتابیس فعلی SQLite ساده است (`users.db`)؛ برای تعداد زیاد کاربر همین کافی است.
- نرخ ارسال بله را رعایت کنید (حداکثر ۲ پیام در ثانیه به هر گفتگو) — در کد یک
  تأخیر کوچک بین ارسال‌ها گذاشته شده.
